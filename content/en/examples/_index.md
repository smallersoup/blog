## Blog source

[smallersoup/blog](https://github.com/smallersoup/blog) contains this site's source. It uses Hugo with the Blowfish theme and is published through GitHub Pages.

Articles are stored in `content`, and layout extensions are in `layouts`. Report article corrections and broken links through the repository's Issues.

See the [author's GitHub profile](https://github.com/smallersoup) for other public repositories.
