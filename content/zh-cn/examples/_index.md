## 博客源码

[smallersoup/blog](https://github.com/smallersoup/blog) 是本站的源码仓库。网站使用 Hugo 构建，采用 Blowfish 主题，并通过 GitHub Pages 发布。

文章内容位于 `content` 目录，布局扩展位于 `layouts` 目录。文章勘误或链接失效可以通过仓库的 Issues 反馈。

更多公开仓库见[作者的 GitHub 主页](https://github.com/smallersoup)。
