本政策适用于小碗汤维护的 kubeinfo.cn 技术博客。隐私问题可通过[联系与勘误](/contact/)页面列出的渠道反馈。

## 访问网站时的数据

本站通过 GitHub Pages 托管，并使用 Cloudflare 提供网络服务。浏览器请求页面、图片、字体或脚本时，相关服务方会接收处理请求所需的信息，包括 IP 地址、请求时间、页面地址、浏览器信息和必要的网络日志。具体处理方式请参阅 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)和 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

本站使用浏览器本地存储保存浅色或深色外观等界面偏好。浏览器设置中可以清除此类数据。

## Google 广告和 Cookie

本站已接入 Google AdSense 广告代码。是否实际展示广告，取决于账号审批、用户选择、地区及广告供应情况。

第三方供应商，包括 Google，会根据用户之前访问本站或其他网站的记录，使用 Cookie 投放广告。Google 及其合作伙伴可以通过广告 Cookie，根据用户访问本站和互联网上其他网站的记录投放广告。相关服务也可能使用网络信标、IP 地址或其他标识符进行广告投放、衡量效果和防止无效流量。

用户可以访问 [Google 广告设置](https://myadcenter.google.com/)管理个性化广告，也可以访问 [AboutAds 的选择页面](https://optout.aboutads.info/)了解并选择停用参与该计划的第三方供应商的个性化广告 Cookie。停用个性化广告不等于不再展示广告。

有关 Google 如何使用合作伙伴网站上的数据，请阅读 [Google 的合作伙伴网站数据使用说明](https://policies.google.com/technologies/partner-sites)。第三方广告服务的可用选择还受各服务方政策及适用地区要求影响。

## 访问统计和使用分析

本站配置了 Google Analytics、Microsoft Clarity、百度统计、Umami 和访问量计数服务，用于了解页面访问和使用情况。Google Analytics 通过 ga.kubeinfo.cn 加载，使用自有域名不改变其作为 Google 服务的性质。

这些服务可能处理页面地址、来源页面、浏览器和设备信息、访问时间及 Cookie 或其他标识符。Microsoft Clarity 还可能记录页面交互和会话重放数据。各服务收集的项目及保留时间依其配置和服务方政策而定。

相关政策见 [Google 隐私政策](https://policies.google.com/privacy)、[Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)、[百度隐私政策](https://privacy.baidu.com/policy)和 [Umami 隐私政策](https://umami.is/privacy)。

本隐私政策、关于本站和联系页面不加载本站配置的广告及统计跟踪脚本。

## 评论、订阅和外部资源

文章评论通过 [Giscus](https://giscus.app/)及 GitHub Discussions 提供。评论会公开显示，登录及评论数据受 GitHub 的相关政策约束。请勿在评论中公开敏感信息。

本站还配置了 Webpushr 浏览器推送服务。浏览器通知权限可在浏览器设置中管理或撤回，数据处理方式参见 [Webpushr 隐私政策](https://www.webpushr.com/privacy-policy)。

文章图片、字体和部分脚本可能由 jsDelivr 等外部服务提供。加载这些资源时，浏览器会向资源所在服务发起请求。外部网站有各自的隐私政策，访问本站中的外部链接后请查阅对应说明。

## 你的选择

你可以在浏览器中管理或清除 Cookie、本地存储和网站通知权限，也可以使用上文提供的广告偏好入口。部分设置可能影响评论、外观偏好或其他功能。不同设备和浏览器的选择需要分别设置。

如需反馈与本站有关的数据问题，请提供相关页面、问题描述和便于定位的必要信息，通过[联系与勘误](/contact/)页面与作者沟通。请不要在公开反馈中提交敏感资料。
