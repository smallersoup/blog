本站由小碗汤维护。文章勘误、链接失效、版权或隐私方面的问题，都可以通过下面的公开渠道联系。

- 在 [博客 GitHub 仓库的 Issues](https://github.com/smallersoup/blog/issues)中提交反馈，或查看[作者 GitHub 主页](https://github.com/smallersoup)。
- 通过本站已有的[微信二维码](/img/wechat-qr-code.jpg)联系。

反馈技术问题时，请附上文章链接、使用的软件版本、复现步骤和已经脱敏的错误信息。这样更容易定位问题。

GitHub Issues 和文章评论是公开内容，请勿提交密码、访问令牌、身份证件或包含他人个人信息的日志。涉及隐私的信息，请使用非公开沟通方式。

如果反馈涉及引用材料或图片，请提供页面地址、对应内容和权利来源，以便核对处理。
